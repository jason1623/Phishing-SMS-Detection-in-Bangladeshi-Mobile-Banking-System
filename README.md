# Phishing-SMS-Detection-in-Bangladeshi-Mobile-Banking-System
In this paper, we propose a high precision bilingual machine learning framework to intercept SMS phishing in Bangladesh’s MFS sector (bKash, Nagad, Rocket). It protects end-users against predatory social engineering, in particular fraudulent alerts that are designed to harvest credentials or extract funds.
